css（层叠样式表）

CSS 全称：**Cascading Style Sheets，是一种样式表语言 作用：给 HTML 网页打扮、设置样 式**。HTML 负责网页有什么内容 （文字、图片、新闻标题），CSS 负责这些内容长什么样（颜色、 大小、背景、排版、间距）。

CSS 有三种引入方式，分别是行内样式、内部样式表和外部样式表。行内样式直接写在标签当中，适合临时调整小细节，但不方便统一管理；内部样式写在网页头部的 style 标签内，适合单个独立网页；外部样式表是单独的 css 文件，多个网页可以共用同一份样式，是正式网站开发里最常用的方式。
